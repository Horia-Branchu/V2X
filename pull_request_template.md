## Pull Request template

Here one can find a template with things that should appear in a PR.

Basically your pull request should contain the following information:


  - A reference to a related task in OpenProject.
  - A description of the changes proposed in the pull request.
  - @mentions of the person for reviewing proposed changes.


---
OpenProject task: #123

Description: Write here the description for the pull request.

@mention of the person assigned to reviewing the PR. 

---
